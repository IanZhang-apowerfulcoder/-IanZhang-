# 已知限制与后续施工项

本文件用于防止将“施工基线已经定义”误表述为“生产系统已经全部实现”。

## 已经完成并验证

- 九人职责、八阶段任务、接口所有权和质量门禁已经冻结；
- Public API、Internal API、知识服务 API、45 份 JSON Schema 和 73 组 HTTP Mock 已通过结构校验；
- 七个核心 Agent、七个平行专业子 Agent、有限并行、唯一仲裁和 Event/Trace 已形成机器契约；
- 企业级 RAG 工程知识库 v2 可本地运行，93 个知识点均具有完整教学资产；
- 知识服务 13 项自动测试、数据库 dry-run 和固定检索基线已通过；
- 自适应多策略 RAG 与平行 Agent 观测台原型可离线演示。

## 尚未完成或不能提前宣称完成

1. 学员端、管理端、业务后端和 Agent Runtime 当前为施工骨架、契约、Mock 与参考实现，不是最终生产应用。
2. 尚未绑定最终大模型、Embedding 模型和 Reranker，也没有在仓库中保存任何 API Key。
3. 372 个知识切片当前的固定评测是词法、字符 n-gram 和元数据基线；不能把它冒充为最终稠密向量与重排效果。
4. Graph-Assisted 使用显式知识边；不等同于已经完成完整 Global GraphRAG 社区发现与全局摘要。
5. Parent-Child、Hybrid、Metadata 和 Agentic 的接口与策略已冻结，但完整生产索引、并发控制和性能优化仍是团队阶段任务。
6. 第二份专业 AI 知识包已经进入可运行统一层，但保持 `pending_team_review`，不得对外宣称已完成人工专家逐条审核。
7. 赛题要求的“幻觉率 <5%”“画像-资源适配准确率 >=85%”必须在最终模型、Prompt、审核 Agent 和人工金标准确定后实测；当前没有虚构这些结果。
8. 当前没有完成公网部署、渗透测试、大规模并发压测和灾难恢复演练。
9. 平行 Agent 是否优于单路流程必须通过 S6 消融实验验证，不能仅凭架构复杂度认定效果更好。

## 发布前必须完成

- 按 `docs/14_测试与验收标准.md` 建立最终金标准集；
- 完成真实模型与检索组件接入；
- 完成端到端应用、权限、幂等、超时、重试、回滚和人工复核；
- 完成普通 RAG、并行 RAG、Agentic 补检索和多维审核的消融实验；
- 由 P1 批准知识库正式版本和比赛口径。
