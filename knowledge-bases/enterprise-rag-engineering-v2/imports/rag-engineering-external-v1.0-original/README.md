# RAG工程实训知识库 v1.0.0

这是面向“领域知识个性化生成与多智能体协同决策”项目的实际知识库成品，领域选择为 **RAG工程实训**。

## 直接使用
- `importable_package/`：与项目V8.1知识包契约兼容的8个顶层文件。
- `rag_engineering_competition_v1_importable.zip`：可直接作为知识库包导入。
- `extended/`：概念卡、FAQ、错误案例、对比案例、代码骨架、画像和章节测评蓝图。
- `documents/`：12章中文学习文档。
- `corpora/`：JSONL检索与评测语料。
- `reports/`：结构质量报告和人工复核清单。

## 当前规模
- 28个来源
- 61个知识节点，其中38个核心节点
- 100条知识关系
- 244个可检索片段
- 15个实操任务
- 183道分阶题目
- 141个评测案例
- 5组差异化虚拟学习者画像

本包已经完成Schema、哈希、引用和覆盖结构检查，但没有冒充“专家已审核”。赛前应按照 `reports/human_review_checklist.md` 完成人工抽查并签字。
