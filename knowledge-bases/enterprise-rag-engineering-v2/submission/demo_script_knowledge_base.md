# 知识库演示脚本

1. 打开领域总览，展示 93 个知识点与 252 条关系；
2. 展示一个 trusted_core 节点和一个 trusted_ai_generated 节点的来源、切片、题目、任务与审核状态；
3. 对简单定义问题执行 Hybrid Retrieval；
4. 对“前置知识和学习路径”执行 Graph-Assisted Retrieval；
5. 对复杂故障问题由 RAG Router 选择 Hybrid + Graph，并触发受限 Agentic 分解；
6. 展示每一步 Retrieval Trace、evidence_id、充分性判断和停止原因；
7. 展示讲义、实操和题目三个平行生成分支；
8. 展示事实、难度、题目、安全四个平行审核分支；
9. 展示审核打回或唯一仲裁；
10. 展示团队复核队列、版本发布和回滚能力。
