# 知识库总说明

本知识库是比赛主系统的预建专业知识底座。运行时不由 Agent 临时创造专业事实，而是由 Agent 从已发布版本检索证据并生成个性化资源。

## 资产

- 8 个模块；
- 93 个知识节点；
- 252 条关系；
- 372 个可追溯知识切片；
- 93 张概念卡、279 条 FAQ、186 个错误案例；
- 372 道题、93 个工程任务、93 套评分标准；
- 279 个检索评测案例、173 个生成评测案例。

## 内容层

`trusted_core` 与 `trusted_ai_generated` 均可用于运行时。后者的 `pending_team_review` 是审计状态，不代表内容禁用；团队后续复核后创建新版本，不原地覆盖 v2。
