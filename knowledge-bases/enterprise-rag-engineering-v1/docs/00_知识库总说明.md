# 企业级 RAG 系统工程与可信知识应用实训知识库

版本：`1.0.0`  
Domain Pack ID：`9cad1d21-24ee-58d2-998c-ea11b5cb9904`  
知识库版本 ID：`fd400183-2242-50aa-8b83-d670c1ce5a1f`

## 1. 定位

本知识库面向高校与企业的 RAG 系统工程技能培训。它不是普通问答语料集合，而是一套同时服务于检索、个性化资源生成、测评、审核和学习路径决策的结构化 Domain Pack。

## 2. 交付范围

- 8 个模块、32 个知识节点；
- 128 个可追溯知识切片；
- 概念卡、FAQ、误区案例、题库、实操任务、Rubric；
- 检索与生成评测集；
- 三类学习者画像及端到端样例；
- 可运行的词法+元数据检索服务；
- OpenAPI、JSON Schema、数据库迁移和现有仓库兼容映射；
- 比赛提交所需的专业知识库切片和完整输入输出样例。

## 3. 核心原则

1. 专业事实来自登记来源，AI 仅辅助结构化和教学重组。
2. 发布后的知识版本不可原地修改。
3. 每个关键结论能追溯到 evidence_id、chunk_id、document_id 和 source_id。
4. 知识库外问题拒答或转人工，不使用模型常识补齐专业事实。
5. 嵌入向量必须由部署时选定的模型实际生成，本包不伪造向量。

## 4. 快速运行

```bash
python scripts/validate_pack.py
python scripts/run_retrieval_eval.py
uvicorn server.app:app --reload --port 8090
```

默认服务会使用本地 BM25/字符 n-gram 与元数据增强检索。后续可接入 pgvector、稠密嵌入和重排器，而不改变现有检索响应契约。
