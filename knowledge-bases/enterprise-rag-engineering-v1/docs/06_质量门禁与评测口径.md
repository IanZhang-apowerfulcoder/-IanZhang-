# 质量门禁与评测口径

## 发布前自动门禁

- JSON/JSONL/YAML 可解析；
- ID 唯一，所有引用存在；
- 32 个节点均有概念卡、至少 4 个切片、3 个 FAQ、2 个误区、4 道题、1 个任务、1 个 Rubric；
- 核心节点来源和证据完整；
- 本地检索基线运行完成；
- 现有项目 retrieval request/response Schema 兼容测试通过；
- 阻断级安全样例不得通过发布。

## 指标定义

- 核心知识点覆盖率 = 达到内容门槛的核心节点数 / 核心节点总数；
- Hit@5 = top-5至少包含一个期望节点的案例数 / 总案例数；
- MRR = 首个期望节点排名倒数的平均；
- 专业知识谬误率 = 被确认错误的专业陈述数 / 被审查专业陈述总数；
- 难度适配准确率 = 资源难度被人工标注为匹配的样本数 / 资源样本总数。

最后两项必须在接入真实生成模型后由人工黄金集或经校准的审核流程测量。本包只提供测试集、Rubric与计算脚本，不填造结果。
