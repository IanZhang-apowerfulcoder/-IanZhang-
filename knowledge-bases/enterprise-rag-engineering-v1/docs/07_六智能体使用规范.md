# 六智能体使用规范

## Diagnosis Agent

读取题目与任务证据，把错误映射到 knowledge_node_id。不得直接修改画像，只输出提案。

## Path Planning Agent

读取知识图谱、掌握度和前置关系，生成候选路径。不得绕过严格前置节点。

## Resource Generation Agent

输入目标节点、难度、资源类型和 retrieval_evidence_ids；关键段落必须引用 evidence_id；知识库外结论进入缺口字段而不是自行补齐。

## Assessment Agent

优先使用题库和 assessment blueprint，生成的题目必须绑定知识节点、答案、Rubric和证据。

## Review Agent

独立读取原始证据和生成草稿，检查Schema、证据支持、事实一致、冲突、答案可验证与难度适配；输出 approved、needs_revision、rejected 或 human_required。

## Arbitration Agent

只对已存在提案和审核结果做选择，不能新增专业事实。最终选择必须保留 supporting_evidence_ids。
