# 领域选择与赛题对齐

## 选择结果

领域确定为：**企业级 RAG 系统工程与可信知识应用实训**。

## 选择依据

1. 属于赛题明确允许的“特定软件开发”和“人工智能”垂直技能场景。
2. 可提供讲义、实操指南、分阶测试题三类以上资源。
3. 每个专业结论可绑定论文、官方文档、标准或经过审核的自编讲义。
4. 可构建从初学者到架构负责人的差异化画像，适合展示难度适配。
5. 与项目本身的 RAG、多 Agent、审核和可视化架构一致，可以让作品“使用自身所教授的技术”。

## 赛题硬要求映射

| 赛题要求 | 本知识库对应内容 |
|---|---|
| 至少一个垂直领域专业知识库切片 | `submission/vertical_domain_knowledge_base_slice.json` |
| 学习者画像 + 专业知识库 | `data/learner_profiles.json` + `data/rag_chunks.jsonl` |
| 定制资源、实操指南、分阶题 | `data/personalized_resource_examples.json`、`task_bank.json`、`question_bank.json` |
| 高保真与知识溯源 | `source_registry.json`、`evidence_items.json`、审核规则 |
| 幻觉率、适配率、覆盖率 | 评测集、指标定义与质量门禁；不伪造尚未运行的模型指标 |
| 可迁移性 | Domain Pack、API、Schema 和导入脚本均与业务系统解耦 |

## 为什么不把“自动生成知识库”作为主闭环

比赛核心是基于专业知识库动态生成个性化学习资源。自动知识工程可以作为扩展能力，但预先准备、验证并冻结一个 Domain Pack 更容易稳定测量知识覆盖、检索质量和专业谬误率。
