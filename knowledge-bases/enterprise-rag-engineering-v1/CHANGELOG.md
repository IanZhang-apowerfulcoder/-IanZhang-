# Changelog

## 1.0.0 - 2026-07-31

- 建立“企业级 RAG 系统工程与可信知识应用实训”预建专业知识库；
- 提供 8 个模块、32 个知识节点、91 条关系和 128 个专业切片；
- 配套概念卡、FAQ、误区、题库、工程任务、Rubric 和固定评测集；
- 提供 3 组差异化学习者完整 Agent 输入输出案例；
- 提供兼容现有项目的检索接口、OpenAPI、JSON Schema 和数据库迁移；
- 提供 FastAPI 服务、检索基线、导入脚本、知识库浏览器和 CI；
- 明确未伪造稠密向量、幻觉率和难度适配率，相关指标待真实模型接入后测量。
