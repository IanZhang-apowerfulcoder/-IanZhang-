# 开发启动清单

## 仓库

- [ ] 邀请九名成员并接受邀请。
- [ ] 创建 `develop`。
- [ ] 保护 `main` 和 `develop`。
- [ ] 配置 CODEOWNERS。
- [ ] 配置 PR 模板和 CI。

## 契约

- [ ] OpenAPI V1 批准。
- [ ] 六智能体 Schema V1 批准。
- [ ] 字段字典和错误码批准。
- [ ] TypeScript 和 Python 类型可用。
- [ ] Mock 全部通过 Schema 校验。

## 架构

- [ ] 前端不直接调用智能体。
- [ ] 后端有展示适配层。
- [ ] 会话和事件可持久化。
- [ ] 组织隔离规则确定。
- [ ] 测评答案过滤规则确定。

## 团队

- [ ] 每人确认角色。
- [ ] 每人确认 Mentor 和 Reviewer。
- [ ] 每人完成练习 PR。
- [ ] 每个阶段有任务卡和验收人。

## 开工条件

以上任一核心契约未完成，不允许多人并行编写真实业务代码。
