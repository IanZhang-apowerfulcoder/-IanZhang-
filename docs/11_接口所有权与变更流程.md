# 接口所有权与变更流程

- Public API 实现 Owner：P5；
- Runtime/Internal API Owner：P2；
- 数据约束 Owner：P6；
- Knowledge/Retrieval Contract Owner：P7；
- 学习者业务语义 Owner：P3；
- Resource Contract Owner：P8；
- Review Contract Owner：P9；
- 最终批准：P1。

任何破坏性变更必须提交 `templates/API_CHANGE_REQUEST.md`，说明影响的页面、服务、Schema、Mock、迁移、回滚和版本策略。批准前不得先改代码再补文件。
