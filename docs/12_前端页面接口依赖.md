# 前端页面与接口依赖

## 学员端

1. 登录与建档；
2. 前测；
3. 学员主页；
4. 画像与盲区；
5. 学习路径；
6. 个性化资源（讲义/实操/题目）；
7. 作答与反馈；
8. 专业问答；
9. 当前工作流状态；
10. 历史学习周期。

## 管理端

1. 总览；
2. 学员列表与详情；
3. 知识库版本；
4. 结构化导入；
5. 审核队列；
6. 知识图谱；
7. 检索测试；
8. Workflow/Agent Trace；
9. Retrieval Trace；
10. 质量指标和消融实验。

每个页面的 operationId 和 Mock 映射见 `project/frontend_page_api_matrix.yaml`。前端不得把定时器动画当真实 Agent 状态；演示回放必须标记为 replay。
