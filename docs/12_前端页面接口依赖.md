# 前端页面与接口依赖

## 管理端

| 页面 | 主要负责人 | 接口 |
|---|---|---|
| 知识库列表 | 陈严谨 | `GET /knowledge-bases` |
| 新建知识库 | 陈严谨 | `POST /knowledge-bases` |
| 文档上传 | 陈严谨 | `POST /documents` |
| 文档状态 | 陈严谨 | `GET /documents/{document_id}` |
| 启动构建 | 陈严谨 | `POST /build-runs` |
| 构建进度 | 陈严谨 | `GET /build-runs/{build_run_id}` |
| 质量报告 | 陈严谨、陈尧 | `GET /quality-report` |
| 智能体运行记录 | 陈严谨 | `GET /learning-sessions/{session_id}/events` |

## 学习端

| 页面 | 主要负责人 | 接口 |
|---|---|---|
| 学习首页 | X | `GET /learners/{learner_id}/profile`、`GET /learning-path` |
| 创建学习会话 | X | `POST /learning-sessions` |
| 会话状态 | X | `GET /learning-sessions/{session_id}` |
| 决策时间线 | X、陈尧 | `GET /events` |
| 学习资料 | 郑翘楚 | `GET /resources` |
| 测评作答 | 李汝萱 | `GET /assessment`、`POST /assessment-attempts` |
| 测评结果 | 李汝萱 | `GET /assessment-attempts/{attempt_id}` |
| 最终决策 | X、陈尧 | `GET /decision` |
| 画像变化 | X、陈尧 | `GET /profile` |

## 页面必须覆盖的状态

- `loading`
- `empty`
- `error`
- `success`
- `permission_denied`
- 异步页面增加 `queued`、`running`、`waiting_human_review` 和 `failed`

## 数据消费规则

- 页面只能引用 `contracts/typescript/contracts.ts` 中的类型。
- 不在页面内部重新定义同名接口。
- 未知枚举值显示“未知状态”，不能导致页面崩溃。
- 前端不得根据 `reasoning_summary` 推导业务状态，应使用明确状态字段。
