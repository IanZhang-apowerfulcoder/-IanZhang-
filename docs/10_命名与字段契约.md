# 命名与字段契约

## 一、统一格式

| 对象 | 规则 | 示例 |
|---|---|---|
| JSON 字段 | snake_case | `knowledge_base_id` |
| URL 路径 | 小写短横线 | `/learning-sessions` |
| 数据库表 | 复数 snake_case | `learning_sessions` |
| 数据库字段 | snake_case | `created_at` |
| TypeScript 类型 | PascalCase | `LearningSessionView` |
| Python 类 | PascalCase | `AgentResultEnvelope` |
| 枚举值 | lower_snake_case | `waiting_review` |

## 二、字段后缀

- 主键和外键：`_id`
- 时间：`_at`
- 数量：`_count`
- 分数：`_score`
- 比例：`_ratio`
- 版本：`_version`
- 布尔：`is_`、`has_`、`can_`、`requires_`

## 三、固定标识

```text
organization_id
knowledge_base_id
document_id
build_run_id
learner_id
session_id
run_id
step_id
event_id
resource_id
assessment_id
attempt_id
review_id
decision_id
knowledge_node_id
evidence_id
```

禁止使用：

```text
orgId / org_id / organizationId 混用
user / student / employee 混用表示 learner
result / data / content 表示不明确对象
```

## 四、固定智能体名

```text
diagnosis_agent
path_planning_agent
resource_generation_agent
assessment_agent
review_agent
arbitration_agent
```

## 五、时间和编号

- ID 使用 UUID 字符串。
- 时间统一 UTC ISO 8601，例如 `2026-07-30T15:00:00Z`。
- 前端负责转换本地时区。
- 分数 0-100，置信度 0-1。
- `sequence_no` 从 1 开始并递增。

## 六、版本

所有公共结果必须包含 `schema_version`，初始值为 `1.0.0`。

- 破坏兼容：主版本增加。
- 增加可选字段：次版本增加。
- 文档或校验修复：补丁版本增加。

## 七、空值

- 数组没有内容返回 `[]`，不返回 `null`。
- 可选文本无内容可返回 `null`。
- 必填字段禁止缺失。
- 不得用空字符串代替未知 ID。
