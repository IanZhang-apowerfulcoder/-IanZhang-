# 系统模块边界

```text
apps/web                     学员端、管理端、可观测性
apps/api                     Public API、鉴权、展示适配、业务状态机
services/agent_runtime       Agent 注册、并行调度、RAG Router、仲裁、恢复
services/retrieval           检索执行器、融合、充分性特征
services/agents              七核心 Agent 与平行专业子 Agent
services/evaluation          固定评测、指标、消融实验
knowledge-bases/...          Domain Pack v2 与维护工具
packages/contracts           Schema、TS/Python 类型
```

## 关键边界

- RAG Router Agent 只制定检索计划，不实现检索算法；
- Retrieval Engine 只执行策略和返回 Evidence Bundle，不生成答案；
- 平行生成 Agent 只提交候选资源；
- 平行审核 Agent 只提交维度审核结果；
- Review Coordinator 汇总审核，但不写最终学习路径；
- Arbitration Agent 输出最终动作建议，M05 后端验证后写入权威数据；
- 前端只使用 Public API 和 Event/SSE；
- 知识库维护是管理员离线流程，不属于学习请求主链。
