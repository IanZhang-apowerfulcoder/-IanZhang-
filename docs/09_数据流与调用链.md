# 前端、后端、Agent 与知识库数据流

## 个性化学习资源

```text
前端创建学习会话
→ 业务后端保存请求并创建 Workflow Run
→ Diagnosis / Path Planning
→ RAG Router 生成 Retrieval Plan
→ Retrieval Engine 并行执行策略
→ Evidence Fusion 与 Sufficiency
→ 三路资源生成
→ Resource Coordinator
→ 四路审核
→ Review Coordinator
→ Arbitration
→ 后端验证、持久化并返回 ResourceView
```

## 用户专业问答

```text
用户问题
→ 后端创建 Question Run
→ Router 选择简单/并行/Agentic 模式
→ 证据包
→ Explanation Generator 生成回答草稿
→ Factuality + Safety 审核
→ 返回带来源回答或拒答
```

## 权威写入

Agent 输出均为建议或草稿。只有业务后端完成 Schema、租户、权限、状态和幂等校验后，才能写入资源、画像、路径和最终决策表。
