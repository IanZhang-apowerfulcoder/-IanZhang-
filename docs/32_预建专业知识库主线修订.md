# 预建专业知识库主线修订

## 决策

比赛MVP以预建并验证的垂直领域Domain Pack为权威知识来源。自动知识工程不是用户每次学习时的必经流程，而是后台可选的候选版本生产能力。

## 运行时主链

学习者画像/前测 -> 诊断 -> 路径规划 -> 从已发布知识版本检索 -> 资源/测评生成 -> 审核 -> 仲裁 -> 学习反馈 -> 新画像。

## 知识更新链

管理员提交资料 -> 来源登记 -> 解析/切片候选 -> 评测 -> 人工批准 -> 发布新版本 -> 激活指针切换。失败不影响当前已发布版本。

## 不变边界

- Agent不拥有直接发布知识版本的权限；
- 专业事实必须有来源和evidence_id；
- 生成资源不能反向写入权威知识库；
- 自动生成的题目或摘要默认属于派生内容，需单独审核。
