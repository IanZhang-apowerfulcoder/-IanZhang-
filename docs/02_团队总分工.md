# 九人团队总分工

- 长期角色：项目负责人、产品与系统总架构、Agent Blueprint 与最终验收
- 长期负责：项目范围与比赛对齐；系统总体架构；七核心 Agent 与平行 Agent 蓝图；RAG 路由规则与预算；最终仲裁政策；阶段目标与质量门禁；跨模块集成与最终验收。
