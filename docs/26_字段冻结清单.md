# 字段冻结清单

机器可读定义位于 `api/field_dictionary.yaml`。下列字段自 V5 起冻结。

## 租户与身份

`organization_id`、`user_id`、`actor_user_id`、`learner_id`。

## 知识工程

`knowledge_base_id`、`document_id`、`build_run_id`、`knowledge_base_version_id`、`version_no`、`quality_report_id`、`retrieval_test_run_id`。

## 培训与学习

`training_program_id`、`assignment_id`、`session_id`、`decision_cycle_id`、`cycle_no`、`profile_snapshot_id`、`profile_version_no`、`path_id`、`path_step_id`。

## 智能体联合决策

`agent_run_id`、`proposal_id`、`review_id`、`decision_id`、`action_execution_id`、`agent_code`、`confidence`、`evidence_ids`、`reasoning_summary`。

## 学习内容与测评

`resource_draft_id`、`resource_id`、`resource_section_id`、`assessment_draft_id`、`assessment_id`、`question_id`、`option_id`、`attempt_id`。

## 行为、证据与人工审核

`behavior_event_id`、`client_event_id`、`behavior_summary_id`、`evidence_id`、`human_review_task_id`。

## 链路控制

`request_id`、`correlation_id`、`causation_id`、`idempotency_key`、`schema_version`、`sequence_no`。

## 学习端动作

`action_type`、`reference_id`、`action_status`。

## 测评答案字段

每条答案都必须带：

```text
question_id
answer_type
```

再根据题型选择：

```text
selected_option_ids
boolean_value
text_value
code_value
code_language
client_answered_at
```

不适用字段使用 `null` 或按 Schema 省略，不得塞进一个通用字符串。

## 修改规则

- 改名、删除或改变语义：破坏性变更；
- 增加必填字段：破坏性变更；
- 增加可选字段：仍需审批和更新 Mock；
- 增加枚举值：需确认所有消费者有未知值兜底；
- 成员内部别名必须在模块入口转换，不能向外传播。
