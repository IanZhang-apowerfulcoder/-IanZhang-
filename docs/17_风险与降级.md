# 风险与降级

| 风险 | 降级 |
|---|---|
| 模型超时 | 重试一次，切换备用模型或固定 Mock |
| Router 非法输出 | 使用确定性默认 Hybrid 策略 |
| 多策略部分失败 | 使用达到最低证据门槛的剩余分支 |
| 证据不足 | 查询改写最多 2 次，之后拒答/人工 |
| 平行生成部分失败 | 只发布通过最低完整性要求的资源或转人工 |
| 审核冲突 | Review Coordinator 汇总后交 Arbitration |
| 数据库不可用 | 停止写操作，不使用内存伪装成功 |
| 知识版本错误 | 回滚到上一个 active 版本 |
| 候选/待复核内容 | 明示 provenance，不宣称专家审核完成 |
