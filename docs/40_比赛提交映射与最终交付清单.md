# 比赛提交映射与最终交付清单

## 赛题闭环

学情画像 → 多 Agent 调度 → 专业知识个性化生成 → 交互反馈 → 动态决策更新。

## 必交

- 设计实现方案；
- 作品介绍/PPT；
- 10 分钟以内视频；
- 源码和部署说明；
- 单元/集成/Agent/RAG 测试；
- 至少一个垂直领域知识库切片；
- 至少 3 组差异化学习者完整输入/中间数据/输出；
- 幻觉率、适配准确率、覆盖率的固定数据集和脚本；
- 数据合规声明。

## 演示重点

必须真实展示 RAG Router 的策略选择、平行分支、证据链、审核打回、定向修复、唯一仲裁和画像变化，而不是只展示聊天回答。
