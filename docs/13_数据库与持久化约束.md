# 数据库与持久化约束

## 存储内容

- 组织、用户、权限和学员；
- 画像快照、掌握度事件和更新证据；
- 知识库、版本、来源、节点、关系、切片、向量、题库、任务和审核；
- 学习会话、资源、测评、作答、路径和最终决策；
- Workflow Run、Agent Run、Parallel Group、Tool Call；
- Retrieval Run、Plan、Step、Strategy Result、Evidence Link、Sufficiency；
- Event、Trace、Checkpoint、人工覆盖；
- Prompt、模型、成本、延迟和评测结果。

## 部署

开发期使用本地 Docker Compose：PostgreSQL + pgvector、Redis 和本地文件目录。前端不连接数据库；后端通过 ORM/Driver 访问；Agent 通过 Internal API/Tool Gateway 获取数据。

## 不可覆盖

知识版本、画像快照、资源版本、审核和决策均追加新版本。不得原地改写后失去历史。
