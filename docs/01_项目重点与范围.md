# 项目重点与范围

## 1. 最终定位

本项目是面向高校与企业 RAG 工程技能培训的个性化学习系统。知识事实由预构建、版本化的专业知识库提供；多智能体负责诊断、检索规划、资源生成、审核、测评和路径决策。

## 2. 必做主线

1. 至少一个可提交的垂直领域专业知识库；
2. 学习者画像和前测；
3. RAG Router Agent 根据问题选择检索策略；
4. 多策略检索、证据融合和充分性判断；
5. 三路平行资源生成；
6. 四路平行审核和唯一仲裁；
7. 交互反馈更新画像与路径；
8. Agent/RAG 过程可视化；
9. 固定评测集和可复现指标。

## 3. 不再作为运行时主线

- 用户上传文件后由 Agent 自动分析、切片并建库；
- 自动建库失败会阻断学习流程；
- 所有问题强制使用 Agentic RAG；
- 多个 Agent 同时拥有最终写入权。

## 4. 知识库维护能力

系统仍保留管理员结构化导入、来源登记、知识节点/切片/题库/任务维护、候选审核、索引重建、版本验证、发布和回滚。它是离线维护子系统，不是学习用户每次请求都会运行的 Agent。

## 5. 第一阶段实现的检索策略

- Metadata-Filtered；
- Hybrid；
- Graph-Assisted；
- Parent-Child；
- 受限 Agentic Decomposition。

完整 Global GraphRAG、Multimodal、Code RAG、Self-RAG、CRAG 和 HyDE 仅预留接口或作为后续实验，不得在代码未完成时宣称已经实现。
