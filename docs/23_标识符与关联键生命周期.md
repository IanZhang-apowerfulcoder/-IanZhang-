# 标识符与关联键生命周期

- `correlation_id`：贯穿一次用户请求或学习周期；
- `workflow_run_id`：一条完整工作流；
- `agent_run_id`：一次 Agent 调用；
- `parallel_group_id`：一组并行 Agent；
- `retrieval_plan_id`：Router 的一个计划；
- `retrieval_run_id`：一次计划执行；
- `retrieval_step_id`：单策略或补检索步骤；
- `causation_id`：指向触发当前事件的上游事件；
- `idempotency_key`：防止重复写入。

标识符由后端或 Runtime 生成，前端不得自造权威 ID。
