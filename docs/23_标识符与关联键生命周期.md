# 标识符与关联键生命周期

| 标识符 | 创建方 | 生命周期 | 主要传递范围 |
|---|---|---|---|
| `organization_id` | 组织服务 | 组织长期存在 | 所有业务边界，作为租户隔离键 |
| `user_id` | 认证服务 | 用户长期存在 | 登录上下文和审计 |
| `learner_id` | 学习者服务 | 学习者长期存在 | 任务、会话、画像、路径 |
| `knowledge_base_id` | 知识库服务 | 逻辑知识库长期存在 | 文档、版本、培训项目 |
| `document_id` | 文档服务 | 文档记录生命周期 | 解析、构建、证据 |
| `build_run_id` | 知识工程服务 | 一次构建任务 | 构建事件与结果 |
| `knowledge_base_version_id` | 知识工程服务 | 不可变版本 | 培训项目、会话、检索 |
| `training_program_id` | 培训项目服务 | 一个培训方案 | 分配和学习目标 |
| `assignment_id` | 分配服务 | 某学习者的一项任务 | 启动会话和任务状态 |
| `session_id` | 会话服务 | 一次完整学习过程 | 所有学习与决策数据 |
| `decision_cycle_id` | 编排器 | 一次联合决策轮次 | 智能体、审核、仲裁、可视化 |
| `agent_run_id` | 智能体运行时 | 一次模型/智能体实际调用 | 运行日志、提案、成本和错误 |
| `proposal_id` | 智能体运行时 | 一份候选提案 | 审核、仲裁、轨迹 |
| `review_id` | 审核服务 | 一次提案审核 | 修订、仲裁、轨迹 |
| `decision_id` | 仲裁服务 | 一次最终决策 | 动作执行和审计 |
| `action_execution_id` | 动作执行器 | 一次决策落地动作 | 当前动作与执行结果 |
| `resource_draft_id` | 资源智能体 | 审核前 | 审核服务内部 |
| `resource_id` | 资源服务 | 审核发布后 | 学习端和进度 |
| `assessment_draft_id` | 测评智能体 | 审核前 | 审核服务内部 |
| `assessment_id` | 测评服务 | 审核发布后 | 学习端和作答 |
| `attempt_id` | 测评服务 | 一次作答 | 评分、诊断、画像 |
| `profile_snapshot_id` | 画像服务 | 不可变快照 | 诊断、会话基线、历史 |
| `path_id` | 路径服务 | 当前或历史路径 | 学习端和决策 |
| `human_review_task_id` | 人工审核服务 | 一次人工处理任务 | 管理端和编排恢复 |

## 关联键规则

### request_id

由 API 网关或服务入口创建，只表示一次 HTTP 请求。重试会产生新的 `request_id`。

### correlation_id

由编排器在决策链开始时创建，同一 `decision_cycle_id` 中的检索、智能体、审核、仲裁和执行均使用相同 `correlation_id`。

### causation_id

指向直接触发当前消息的对象，常见值为上游 `event_id`、`agent_run_id`、`review_id` 或 `decision_id`。

### idempotency_key

由调用方创建，用于写操作去重。相同组织、接口和幂等键的重复请求必须返回同一业务结果，不得重复创建任务。

### sequence_no

在同一个 `session_id` 或异步任务事件流内单调递增。前端使用 `after_sequence_no` 增量拉取，不能仅按时间排序。
