# 多智能体联合决策状态机

## 学习主状态

```text
created
→ collecting_context
→ diagnosing
→ planning_path
→ routing_retrieval
→ retrieving_evidence
→ checking_evidence
→ generating_parallel_resources
→ composing_resource
→ reviewing_parallel
→ aggregating_review
→ delivering_resource
→ awaiting_submission
→ evaluating_result
→ arbitrating
→ updating_profile
→ completed
```

异常和控制状态：`retrying`、`waiting_human_review`、`degraded`、`failed`、`cancelled`。

## 检索子状态

`query_analyzed → plan_created → strategies_running → evidence_fused → sufficiency_checked`；证据不足时进入 `query_rewritten / fallback_selected / retrying_retrieval`，最多 2 次。

## 平行组规则

- 任何平行组都有 `parallel_group_id`；
- 允许部分分支失败，但必须根据最低可用分支数决定降级或停止；
- 分支输出不能直接覆盖最终资源；
- 所有分支结束或超时后由 Coordinator 聚合；
- 最终只有一个 Arbitration Decision。
