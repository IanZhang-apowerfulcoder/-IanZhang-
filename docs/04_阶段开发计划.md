# 分阶段开发计划

## S0：范围、架构与契约冻结

目标：冻结产品主线、七核心 Agent、平行 Agent、RAG 策略、接口、字段、数据库实体和验收口径。

进入下一阶段前，所有本阶段核心任务必须 `ACCEPTED`，P0/P1 缺陷必须为 0。

## S1：GitHub 骨架与全 Mock 闭环

目标：所有前端和后端不依赖真实模型，用 Mock 跑通预建知识库、路由、并行生成、并行审核和仲裁。

进入下一阶段前，所有本阶段核心任务必须 `ACCEPTED`，P0/P1 缺陷必须为 0。

## S2：知识库 v2 与检索执行器

目标：完成两份知识库统一接入、持续维护工具、Hybrid/Metadata/Graph-Assisted/Parent-Child 基线和检索评测。

进入下一阶段前，所有本阶段核心任务必须 `ACCEPTED`，P0/P1 缺陷必须为 0。

## S3：RAG Router 与 Agentic Retrieval

目标：实现问题分类、检索计划、有限并行、证据融合、充分性判断、补检索、预算和 Trace。

进入下一阶段前，所有本阶段核心任务必须 `ACCEPTED`，P0/P1 缺陷必须为 0。

## S4：诊断、路径、平行生成与测评

目标：实现学习者模型、诊断、路径、三类平行资源生成、资源编排和测评 Agent。

进入下一阶段前，所有本阶段核心任务必须 `ACCEPTED`，P0/P1 缺陷必须为 0。
