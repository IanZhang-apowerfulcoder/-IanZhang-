# 测试与验收标准

## 契约

- OpenAPI/YAML/JSON 解析率 100%；
- Mock 通过 Schema 率 100%；
- TS/Python 类型与 Schema 一致；
- 72 张阶段任务卡完整。

## 知识与检索

- 核心知识点覆盖率 >=90%；
- 固定集 Recall@5 >=0.90；
- MRR >=0.80；
- evidence/source 断链为 0；
- 路由策略与人工标注一致率 >=90%；
- 无效 Agentic 循环率 <=2%；
- 预算违规为 0。

## Agent 与资源

- 结构化输出成功率 >=99%；
- 知识型结论引用覆盖率 100%；
- 学习者画像—资源难度适配准确率 >=85%；
- 审核后专业知识谬误率 <=5%；
- 资源核心知识点覆盖率 >=90%；
- 并行生成完整性不低于单路基线；
- 审核打回后修复成功率 >=85%。

## 系统

- 跨租户越权成功数 0；
- 高优先级缺陷 0；
- 三类画像完整流程各连续 3 次；
- 关键异常均有降级或人工介入；
- 所有宣传数字由脚本、版本和固定数据集复现。
