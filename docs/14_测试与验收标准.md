# 测试与验收标准

## 契约测试

- OpenAPI 可以解析。
- 所有 Mock 符合对应 Schema。
- TypeScript 和 Python 类型字段一致。
- 未知枚举值有兜底。

## 六智能体测试

每个智能体至少覆盖：

- 正常输出。
- 空证据。
- 低置信度。
- 非法 JSON。
- 超时。
- 模型拒绝或空内容。
- Schema 不匹配。
- 跨租户证据。

## 联合决策测试

至少包含：

1. 诊断与路径一致，正常通过。
2. 路径与诊断冲突，要求重规划。
3. 资源证据不足，被审核驳回。
4. 测评答案不可验证，被重新生成。
5. 连续失败达到上限，转人工。
6. 测评结果与画像冲突，触发重新诊断。

## 前端验收

- 所有页面覆盖加载、空、错误和成功。
- 异步状态可见。
- 引用可以打开来源。
- 未作答前不泄漏答案。
- 决策链顺序正确。
- 小屏幕不影响主流程。

## 目标指标

- 智能体结构化输出解析成功率 >= 99%。
- 支持格式解析成功率 >= 95%。
- 标注集 Recall@5 >= 0.85。
- 知识型内容引用覆盖率 = 100%。
- 跨租户越权成功数 = 0。
- 审核后事实性错误率 <= 5%。
- 关键演示流程连续执行 3 次无阻塞。

目标必须由固定数据集和脚本计算，不能只凭主观评价。
