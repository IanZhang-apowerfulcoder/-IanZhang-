# 跨模块数据传输契约矩阵

机器可读完整版位于 `project/boundary_contract_manifest.yaml`。本文件说明每个交接点必须共同认可的字段。

| 生产方 → 消费方 | 请求中的关键字段 | 响应中的关键字段 |
|---|---|---|
| 登录页 → 认证服务 | `email`、`password` | `access_token`、`refresh_token`、`user_id`、`organization_id` |
| 管理端 → 知识库服务 | `knowledge_base_name`、`domain_code` | `knowledge_base_id`、`status` |
| 上传页 → 文档服务 | `knowledge_base_id`、`file`、`idempotency_key` | `document_id`、`document_status`、`content_sha256` |
| 知识库服务 → 知识工程 | `build_run_id`、`document_ids`、`build_mode` | `knowledge_base_version_id`、`quality_report_id`、`publishable` |
| 管理端 → 培训项目服务 | `knowledge_base_version_id`、`program_name`、`program_target_node_ids` | `training_program_id`、`program_status` |
| 培训项目 → 分配服务 | `training_program_id`、`learner_ids` | `assignment_id`、`learner_id`、`assignment_status` |
| 学习端 → 会话服务 | `assignment_id`、`idempotency_key` | `session_id`、`profile_snapshot_id`、`knowledge_base_version_id` |
| 会话服务 → 编排器 | `session_id`、`assignment_id`、`profile_snapshot_id` | `decision_cycle_id`、`cycle_no` |
| 编排器 → 检索服务 | `retrieval_request_id`、`knowledge_base_version_id`、`query_text` | `evidence_id`、`chunk_id`、`relevance_score` |
| 编排器 → 诊断智能体 | `profile_snapshot_id`、`assessment_attempt_id`、`behavior_summary_id`、`evidence_ids` | `proposal_id`、`weak_knowledge_node_ids`、`recommended_focus_node_ids` |
| 编排器 → 路径智能体 | `diagnosis_proposal_id`、`profile_snapshot_id`、`program_target_node_ids` | `proposal_id`、`candidate_steps`、`path_step_id` |
| 编排器 → 资源智能体 | `path_plan_proposal_id`、`path_step_id`、`retrieval_evidence_ids` | `proposal_id`、`resource_draft_id`、`resource_section_id` |
| 编排器 → 测评智能体 | `path_plan_proposal_id`、`path_step_id`、`retrieval_evidence_ids` | `proposal_id`、`assessment_draft_id`、`question_id`、`option_id` |
| 编排器 → 审核智能体 | `reviewed_proposal_id`、`reviewed_agent_run_id`、`reviewed_payload` | `review_id`、`review_result`、`repair_action` |
| 编排器 → 仲裁智能体 | 各类 `proposal_ids`、`review_ids` | `proposal_id`、`decision_type`、`selected_proposal_ids` |
| 仲裁服务 → 动作执行器 | `decision_id`、`action_execution_id`、`action_type` | `execution_status`、`current_action_type`、`session_status` |
| 后端投影 → 学习端 | `session_id`、`decision_cycle_id` | `action_type`、`reference_id`、`action_status` |
| 资源页 → 进度服务 | `resource_id`、`progress_status`、`progress_percent` | `updated_at` |
| 测评页 → 测评服务 | `assessment_id`、`answers`、`idempotency_key` | `attempt_id`、`attempt_status`、`next_decision_cycle_id` |
| 测评服务 → 评分服务 | `attempt_id`、类型化 `answers`、`answer_key_reference_id` | `score_ratio`、`error_type_codes`、`mastery_delta_by_knowledge_node` |
| 评分/仲裁 → 画像服务 | `base_profile_snapshot_id`、`base_profile_version_no`、掌握度增量 | `new_profile_snapshot_id`、`new_profile_version_no` |
| 审核服务 → 人工审核 | `session_id`、`decision_cycle_id`、`reference_id` | `human_review_task_id`、`task_status` |
| 可观测性后端 → 决策可视化 | `decision_cycle_id` | `agent_run_id`、`proposal_id`、`review_id`、`decision_id`、`sequence_no` |

## 执行规则

- 请求和响应中出现的字段名称必须与机器可读契约完全一致。
- 同一个对象不得在不同成员模块中使用第二套别名。
- 需要新增字段时先更新 Schema、OpenAPI、Mock 和本矩阵，再修改实现。
- 可选字段也必须在契约中声明，不得在运行时临时追加。
