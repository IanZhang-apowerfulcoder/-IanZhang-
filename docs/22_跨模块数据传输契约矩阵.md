# 跨模块数据传输契约矩阵

关键链路：

- 前端 → 后端：Public OpenAPI；
- 后端 → Runtime：Internal OpenAPI；
- Runtime → Agent：Agent JSON Schema；
- Router → Retrieval Engine：Retrieval Plan；
- Retrieval Engine → Generation/Review：Evidence Bundle；
- Agent → 后端：Schema-validated Artifact；
- 后端 → 数据库：服务层命令；
- 后端 → 前端：稳定 View 与 Event。

完整矩阵见 `project/boundary_contract_manifest.yaml`。
