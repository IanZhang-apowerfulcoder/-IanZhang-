# 知识库持续维护与版本发布

## 内容状态

`draft → candidate → under_review → approved → published`，异常为 `rejected / deprecated`。

## 维护步骤

来源登记 → 节点映射/新增 → 切片与 evidence → 题库/任务/Rubric → Schema 校验 → 抽样专业审核 → 检索回归 → 创建不可变版本 → P1 批准 → publish/activate。

## 接口

系统只接收结构化知识包或已整理的内容，不在 MVP 中用 Agent 自动解析任意文件。结构化导入支持 dry-run、差异报告、冲突报告和回滚。

## 版本

学习会话绑定具体 `knowledge_base_version_id`。新版本发布不改变历史会话；旧版本可继续回放。
