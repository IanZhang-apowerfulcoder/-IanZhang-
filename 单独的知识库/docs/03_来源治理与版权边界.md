# 来源治理与版权边界

## 来源分级

- A 级：赛题文件、同行评审论文、标准、官方项目文档、安全组织指南；
- B 级：成熟开源框架官方文档和经过验证的工程资料；
- C 级：社区文章、论坛、未审核内部草稿，仅可作为候选线索。

本版本专业结论主要使用 A/B 级来源。所有教学正文为原创转述，不大段复制来源原文。

## 强制字段

每个来源记录标题、机构、类型、可信等级、URL或本地引用、验证日期、使用范围和备注。每个切片绑定 source_ids；来源撤回时可通过血缘查找受影响切片、题目与资源。

## 禁止事项

- 不把模型生成内容标记为原始权威来源；
- 不自动抓取并发布未知许可网页；
- 不把内部敏感资料提交到公共仓库；
- 不删除原始出处后只保留摘要；
- 不声称“零幻觉”而没有测试口径和证据。
