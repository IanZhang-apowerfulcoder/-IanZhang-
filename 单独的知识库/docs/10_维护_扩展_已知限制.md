# 维护、扩展与已知限制

## 扩展流程

新内容先进入候选分支：来源登记 -> 内容编写/解析 -> 节点映射 -> 切片 -> 题库/任务补齐 -> 检索回归 -> 审核 -> 发布新版本。禁止直接修改已发布版本。

## 本版本限制

1. 不包含任何伪造的稠密向量；需要按实际选定模型生成。
2. 本地服务是可工作的BM25/字符n-gram基线，不等同于完整生产混合检索。
3. 幻觉率和难度适配准确率依赖真实生成模型和人工标注，本包未宣称已经达标。
4. GraphRAG、跨编码重排和多模态检索提供知识与接口设计，需项目团队按资源实现适配器。
5. 内容聚焦RAG工程，不覆盖通用大模型训练、模型压缩或纯算法研究。

这些限制被明确记录，是为了保持比赛材料可信和可复现。
