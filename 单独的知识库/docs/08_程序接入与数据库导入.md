# 程序接入与数据库导入

## 本地接入

1. 把整个 Domain Pack 放入仓库 `knowledge-bases/enterprise-rag-engineering-v1/`；
2. 后端通过模块方式调用 `server.retriever.DomainRetriever`，或启动 FastAPI 独立服务；
3. 使用 `scripts/import_to_postgres.py` 导入知识节点、切片、题库和评测集；
4. 配置激活的 `knowledge_base_version_id = fd400183-2242-50aa-8b83-d670c1ce5a1f`；
5. Retrieval Agent 通过既有检索请求/响应 Schema 调用。

## 数据库连接

浏览器不连接数据库。业务后端通过 PostgreSQL Driver/ORM 写入权威数据；专业 Agent 通过后端或 Runtime 工具读取快照。`db/migrations/001_domain_pack_extension.sql` 为现有 V6 数据库补充知识节点、关系、切片、题库、任务、Rubric和评测表。

## 向量生成

配置 `EMBEDDING_MODEL_ID`、维度、归一化和距离函数后运行导入适配器。模型变化必须创建新知识版本，不能在原版本中覆盖向量。
