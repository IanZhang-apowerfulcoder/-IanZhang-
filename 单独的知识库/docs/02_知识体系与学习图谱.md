# 知识体系与学习图谱

## 模块结构

1. RAG 基础与方案选择
2. 数据治理与知识构建
3. 表示、索引与基础检索
4. 检索增强与上下文工程
5. 可信生成与安全控制
6. 评测、观测与持续改进
7. 高级 RAG 架构
8. API、性能与生产部署

## 节点规则

每个知识节点都包含：

- 唯一知识节点 ID；
- 难度 1-5；
- 是否属于核心知识；
- 前置知识；
- 学习目标；
- 四个专业事实切片；
- 两个常见误区；
- 适用边界；
- 一项工程任务和一套 Rubric；
- FAQ、题目和检索评测案例。

## 边类型

- `prerequisite_of`：严格前置；
- `recommended_before`：推荐顺序；
- `compared_with`：需要比较；
- `complements`：互补技术；
- `supports` / `prepares`：工程支撑；
- `often_confused_with`：容易混淆；
- `reviewed_by`：审核关系。

路径规划 Agent 应优先使用严格前置关系和学习者掌握度，不允许只根据文本相似度生成学习路径。
