# 比赛提交映射与演示

## 可直接提交的知识库材料

- `submission/vertical_domain_knowledge_base_slice.json`：代表性专业知识切片；
- `submission/learner_cases/`：三组差异化画像、检索证据、资源、测评和决策样例；
- `submission/knowledge_base_submission_overview.md`：知识库介绍与质量口径；
- `submission/data_compliance_statement.md`：数据合规说明；
- `submission/demo_script_knowledge_base.md`：知识库部分演示脚本。

## 建议演示顺序

1. 展示32节点知识图谱和已发布版本；
2. 对同一知识点输入三类画像；
3. 展示Retrieval Agent命中不同证据和路径；
4. 展示生成资源中的evidence_id；
5. 人为引入一个错误，展示Review Agent打回；
6. 展示学习后画像和路径更新；
7. 展示检索评测、覆盖率和尚待真实模型测量的指标，避免虚假宣传。
