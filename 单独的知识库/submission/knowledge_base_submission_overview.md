# 垂直领域知识库提交说明

## 名称与定位

**企业级 RAG 系统工程与可信知识应用实训知识库 v2.0.0**，属于“特定软件开发 / 人工智能工程”垂直技能培训领域。

## 数据规模

- 8 个模块、93 个知识节点、252 条关系；
- 372 个专业切片和 372 个证据项；
- 93 张概念卡、279 条 FAQ、186 个误区；
- 372 道分阶题、93 个实操任务、93 套 Rubric；
- 279 条检索评测、173 条生成/拒答评测；
- 3 组差异化学习者完整 Agent 输入输出样例。

## 内容来源与审核状态

两份专业 AI 知识包均纳入运行时。原 32 节点为 trusted_core；新增 61 节点为 trusted_ai_generated，并保留 pending_team_review。该状态用于诚实说明团队还需逐条复核，不影响开发和内部运行。

## 可信机制

每个切片绑定 `document_id`、`chunk_id`、`evidence_id`、`knowledge_node_id`、`source_ids` 与版本；生成 Agent 只能使用 Evidence Bundle；事实、难度、题目和安全由平行审核分支检查；最终由唯一 Arbitration Agent 裁决。

## 指标声明

本包报告真实固定检索基线。幻觉率和难度适配率须在最终生成模型、Prompt 和人工标注标准冻结后实测，不使用模拟值代替。
